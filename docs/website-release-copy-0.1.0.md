# Website release copy — 0.1.0

## English

**Digicyfr Company Checkout Fields PL** is a free, open-source WooCommerce plugin for two optional checkout values: whether the order is for a company and a Polish NIP. It works with classic checkout and the Checkout Block's Order information section. It keeps WooCommerce's company name field and stores the same order-only data in both checkout paths. Staff see read-only values on the order; customers see them on normal order details and emails. A merchant can turn off this plugin's capture when another extension already asks for NIP, while retaining historic order values.

The local NIP check covers only format and check digit. It does not verify a business, issue invoices, call a registry, or change taxes. NIP can be personal information; normal WooCommerce order privacy export and erasure apply. Uninstall leaves historic order values under the store's control.

Tested version matrix and exact ZIP checksum are in the local QA record. GPL-2.0-or-later; manual ZIP updates. [Public source](https://github.com/digicyfr/digicyfr-company-checkout-fields-pl) is available; the download link is pending publication.

## Polski

**Digicyfr Company Checkout Fields PL** to darmowa wtyczka WooCommerce o otwartym kodzie, która dodaje do zamówienia dwie opcjonalne wartości: oznaczenie zamówienia firmowego i polski NIP. Działa w klasycznej kasie oraz w sekcji informacji o zamówieniu bloku kasy. Zachowuje pole nazwy firmy WooCommerce i zapisuje te same dane wyłącznie przy zamówieniu w obu sposobach składania zamówienia. Pracownicy widzą wartości tylko do odczytu, a klienci na zwykłych stronach zamówienia i w wiadomościach. Sprzedawca może wyłączyć pobieranie przez tę wtyczkę, gdy inna już pyta o NIP, bez usuwania wcześniejszych wartości.

Lokalne sprawdzenie NIP obejmuje tylko format i cyfrę kontrolną. Nie potwierdza firmy, nie wystawia faktur, nie łączy się z rejestrem i nie zmienia podatków. NIP może być daną osobową; zastosowanie mają zwykłe funkcje eksportu i usuwania danych zamówień WooCommerce. Usunięcie wtyczki pozostawia wcześniejsze wartości pod kontrolą sklepu.

Przetestowane wersje i dokładna suma kontrolna ZIP są w lokalnym protokole QA. Licencja GPL-2.0-or-later; aktualizacja przez ręczne wgranie ZIP. [Publiczny kod źródłowy](https://github.com/digicyfr/digicyfr-company-checkout-fields-pl) jest dostępny; odnośnik do pobrania zostanie dodany po publikacji.
