# Company Checkout Fields PL 0.1.0 stable release

SHA-256 of `digicyfr-company-checkout-fields-pl-0.1.0.zip`: `33da10e89d0dc9d00a0c1a30236e1ccd45e91a8b57ba1a53facedc67c70e0379`.

This first version adds optional company intent and Polish NIP to WooCommerce classic and Block checkout, keeping the values on the order. It supports WooCommerce HPOS, historical read-only display, capture disablement, and order privacy export/erasure. English and Polish strings are bundled. Uninstall keeps existing order values under the store's retention policy.

Verified on WordPress 7.1/PHP 8.3.33 with WooCommerce 8.9.0 and 11.2.2 in an eight-cell checkout/storage matrix on a runtime-identical ZIP. The exact public GitHub ZIP passed a fresh WooCommerce 11.2.2 Checkout Block/HPOS contract test, plus post-tag browser checkout tests on Block/HPOS and Classic/legacy: guest and signed-in personal/company orders, both invalid NIP cases, stored order data, receipts with capture on/off, administrator display, and a 390px keyboard Block checkout. Synthetic on-hold HTML and plain email templates showed company details once. Only bundled README files changed after the broader matrix.

An automated Chromium/axe-core audit found zero WCAG A/AA rule violations in the merchant setting, settled Block and Classic checkouts, and visible invalid-NIP states. WooCommerce-only baselines also had zero. The WooCommerce-native Classic order-notes contrast remained inconclusive to axe with the plugin active and inactive; a transient Block loading-skeleton ARIA finding disappeared after loading. Browser and axe checks do not certify WCAG conformance. A manual screen-reader check and merchant acceptance tests with the target theme, checkout, payment and email configuration remain unperformed. Automatic customer email delivery after checkout was not established by the disposable fixture. Intervening or newer WooCommerce versions were not tested. NIP validation checks only format and check digit; it does not verify business identity or tax status. No invoices or tax changes are provided. Updates are manual ZIP installs. See the [post-tag QA record on main](https://github.com/digicyfr/digicyfr-company-checkout-fields-pl/blob/main/docs/QA-0.1.0.md) for full evidence and screenshots.
